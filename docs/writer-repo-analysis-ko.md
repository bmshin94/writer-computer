## 1. 이 프로젝트의 정체

**Writer** — 로컬 마크다운 파일을 읽고 쓰는 **데스크탑 글쓰기 앱**. 옵시디언 계열의
로컬 우선(local-first) 노트 앱이며, 현재 버전은 `v0.6.1` (웹사이트 배지 기준 Beta).

플러그인도, 스킬도, MCP 서버도 아니다. **혼자 실행되는 독립 애플리케이션**이다.

### 기술 스택

| 영역 | 기술 |
|---|---|
| 앱 셸 | Tauri v2 (Rust) |
| 프론트엔드 | React 19 + TypeScript + Zustand + Tailwind v4 |
| 에디터 | CodeMirror 6 (자체 "Prosemark" 레이어) |
| 백엔드 | Rust (파일 I/O, 워크스페이스 인덱싱, 워처, 검색) |
| 툴체인 | **Vite+ (`vp` CLI)** — npm/pnpm 직접 호출 금지 |
| 웹사이트 | TanStack Start + Cloudflare Workers |
| 라이선스 | **GPL-3.0** |

### 코드 규모 (조사 시점)

| 항목 | 수치 |
|---|---|
| TS/TSX | 28,491줄 / 234개 파일 |
| Rust | 10,056줄 |
| 문서 (`docs/` + `SPECs/`) | 7,840줄 |
| 기능 기획서 (`SPECs/`) | 53장 |
| 에이전트 워크시트 (`SPECs/Agent/`) | 13장 |

## 4. 설치 및 사용법

### 완성품으로 쓰기 (권장)

인앱 업데이터가 **원본 레포**를 가리키므로, 설치 파일은 원본 릴리즈에서 받는다.

- https://github.com/joelbqz/writer-computer/releases → `.dmg` (macOS 전용)

### 직접 빌드

사전 요구사항: macOS / Node 22.12+ / pnpm 10.32.1 / Rust / **Vite+ (`vp`)**

```bash
vp install     # 의존성 설치
vp dev         # 개발 모드 실행
vp check       # 포맷 + 린트 + 타입체크
vp test        # JS/TS 테스트
```

Rust 검증 (`apps/desktop/src-tauri/`에서):

```bash
cargo test
cargo clippy
cargo fmt --check
```

> ⚠️ `npm install` / `pnpm install` 직접 호출 금지. 이 레포는 `vp`만 사용한다.
> 배포 빌드(`scripts/distribute.sh`)는 master 브랜치, 클린 트리, 애플 서명 자격증명이
> 모두 갖춰져야 실행된다.

## 6. API 토큰 필요 여부

**앱 사용에는 불필요하다.** 코드 전수 검색 결과 OpenAI/Anthropic 등 **LLM 연동이 전혀 없다.**
현재 Writer에는 AI 기능 자체가 없다.

키가 등장하는 곳은 세 군데뿐이며, 모두 일반 사용자와 무관하다.

| 키 | 용도 | 필요 시점 |
|---|---|---|
| `WRITER_POSTHOG_KEY` | 옵트인 사용 통계 | 배포 빌드 시에만 (선택) |
| 웹사이트 PostHog 키 | 랜딩 페이지 분석 | 웹사이트 배포 시에만 |
| 애플 서명/공증 자격증명 | 릴리즈 배포 | 정식 배포 시에만 |

### 프라이버시 설계

텔레메트리가 3중으로 잠겨 있다.

1. 빌드 시 `WRITER_POSTHOG_KEY`가 없으면 **코드에 컴파일조차 되지 않는다** (`option_env!`)
2. 키가 있어도 **기본값이 꺼짐** — 사용자가 직접 켜야 한다
3. 별도 킬 스위치 존재

수집하더라도 **문서 내용, 파일 이름, 경로는 전송하지 않는다.** 이 레포를 클론해서
직접 빌드하면 구조적으로 아무것도 나가지 않는다. 상세는 [`docs/telemetry.md`](./telemetry.md).

## 7. 이 레포의 진짜 가치: AI 에이전트 개발 워크플로우

앱 코드보다 **개발 프로세스 문서 세트**가 더 희소한 자산이다. 커밋 132개가 실제로
이 방식으로 돌아갔다.

### 핵심 파일 5종

| 파일 | 역할 |
|---|---|
| `AGENTS.md` | **에이전트 라우터** — 작업 의도에 따라 읽을 문서로 안내 |
| `docs/workflows/agent-loop.md` | 자율 실행 루프 (Step 0~7) |
| `docs/workflows/agent-review.md` | 리뷰 페르소나 + 발견사항 포맷 + 에스컬레이션 규칙 |
| `TODOS.md` | 백로그 3단 구조 (Up Next → In Progress → Done) |
| `SPECs/` | 사람이 쓰는 기능 요청서 |

### 실행 루프 요약

```
Step 0  준비      — 워킹트리 확인 + 전체 검증 통과시키고 시작
Step 1  선택      — Up Next에서 가장 작은 항목 1개, In Progress로 이동
                    SPECs/Agent/worksheet-<slug>.md 생성 (하드 요구사항)
Step 2  조사      — 스펙/문서/코드 읽기, 버그는 실패 테스트부터
Step 3  계획      — 목표/발견/변경범위/문서갱신/테스트전략/리스크를 워크시트에
Step 4  계획 리뷰 — 페르소나별 서브에이전트를 새 컨텍스트로 스폰
Step 5  구현      — 작게 쪼개서 검증하며 진행
Step 6  구현 리뷰 — 다시 페르소나 리뷰
Step 7  마무리    — CHANGELOG 갱신, 작업 1개당 커밋 1개
```

### 리뷰 페르소나 8종

React/Frontend · Zustand/State · Editor · Rust/Tauri · Startup/Workspace ·
UX · Systems Architect · QA Engineer

각 페르소나는 **자기가 소유한 문서**를 갖고, 변경된 영역에 따라 선택적으로 활성화된다.

### 훔쳐올 만한 원칙 3가지

1. **컨텍스트 격리** — 구현한 에이전트가 자기 걸 리뷰하면 안 된다. 이미 자기 결정을
   합리화했기 때문에, 같은 맥락을 공유한 리뷰어는 그 가정을 그대로 반복한다.
2. **한 번에 하나** — 자율 모드에서는 정확히 한 작업만 하고 즉시 커밋. 배치 금지.
3. **추측 금지** — "한 번 고쳐서 안 되면, 접근을 또 바꾸지 말고 디버그 로그부터 넣어라.
   런타임이 어느 항이 틀렸는지 말해주게 하라."

### Engineering Guardrails (요약)

- 올바르고 견고하면서 **가장 작은 변경**을 선호
- 취약한 로직, 숨은 결합, 우연한 실행 순서 의존 회피
- 비동기/공유 상태는 레이스 안전하게 (명시적 순서·취소·멱등성)
- 불필요한 성능 회귀 금지 (추가 렌더/할당/구독/스캔/블로킹 I/O)
- **명시적 실패** — 에러를 조용히 삼키거나 폴백으로 가리지 말 것
- 테스트 가능성 유지 — 사이드이펙트는 경계로
- 트레이드오프는 명시하고, 장기 유지보수 리스크가 낮은 쪽 선택

## 8. 라이선스 (GPL-3.0) — 수익화 전 필독

| 가능 | 불가능 |
|---|---|
| 돈 받고 판매 (GPL은 "무료" 의무가 아님) | 소스 숨기고 배포 |
| 수정 후 배포 (소스 동봉 조건) | 라이선스 변경 |
| **서버 서비스 운영 — 서버 코드 비공개 가능** | macOS 앱스토어 등록 (GPL↔애플 약관 충돌) |
| 사내 사용 (배포 아님) | "Writer" 상표 사용 (상표권은 별개) |
| **읽고 배워서 내 저작물 만들기** | `docs/`·`SPECs/` 파일 원문 그대로 판매 |

### 핵심 포인트 2가지

1. **GPL-3.0은 AGPL이 아니다.** 네트워크 서비스 제공은 "배포"가 아니므로,
   별도 백엔드/서버 코드는 비공개로 둘 수 있다.
2. **방법론·아이디어에는 저작권이 없다.** 문서를 복사하면 위반이지만,
   읽고 배워서 자기 언어로 다시 쓴 결과물은 본인 저작물이다.

> ⚠️ 법률 자문이 아니다. 실제 사업화 전 전문가 확인 필요.

## 9. 수익화 검토

### 전제: 이 레포는 "내 것"이 아니다

커밋 132개 중 내 기여는 4개(CLAUDE.md 추가)뿐이다. 따라서 **제품 자체를 파는 경로는
법적·도의적으로 제약이 크다.** 반면 **여기서 배운 방법론은 온전히 내 것**이다.

### Tier A — 즉시 가능 (라이선스 리스크 없음)

| # | 아이디어 | 추천도 | 형태 / 가격대 |
|---|---|---|---|
| A-1 | AI 에이전트 개발 방법론 콘텐츠 | ★★★★★ | 블로그(무료) → 전자책(2~5만) → 강의(5~15만) |
| A-2 | 기업 컨설팅 / 사내 도입 지원 | ★★★★★ | 진단·구축·정착 패키지 (단가 최상) |
| A-3 | "AI 개발 스타터 킷" 판매 | ★★★★☆ | 템플릿 묶음 3~10만원 (Gumroad/크몽) |

> A-3은 반드시 **원문 복붙 없이 재작성**해야 한다. 본인 프로젝트에 직접 적용한 뒤
> 거기서 나온 자기 버전을 상품화하는 것이 안전하고 품질도 높다.

### Tier B — 중기 (개발 필요, 3~6개월)

| # | 아이디어 | 추천도 | 메모 |
|---|---|---|---|
| B-1 | 클라우드 동기화 구독 | ★★★★☆ | GPL 합법(서버 비공개 OK). 단 "로컬 전용" 정체성과 충돌, 옵시디언 Sync와 경쟁 |
| B-2 | **웹 퍼블리싱 서비스** | ★★★★★ | 노트 → 블로그/위키 1클릭 발행. 프라이버시 충돌 없음, 기존 렌더링 자산 재활용 |
| B-3 | 직군 특화 버전 | ★★★☆☆ | 웹소설 작가용이 가장 유망. 앱은 무료 + 템플릿/에셋 판매 |

### Tier C — 장기 / 보조

- GitHub Sponsors (국내에선 실효성 낮음)
- 오픈소스 유상 지원 계약
- **원작자와 파트너십** — 라이선스 이슈를 가장 깔끔하게 해소하는 경로

### 금지 항목

- 이름만 바꿔 앱스토어 유료 등록 (GPL + 애플 약관 이중 위반)
- 소스 비공개 상용 배포
- `docs/` · `SPECs/` 원문 판매
- "Writer" 브랜드 도용
- 원작자 미표기

### 90일 실행안

```
1개월차  블로그 3편 발행 → 내 프로젝트에 워크플로우 직접 적용(적용기를 기록)
2개월차  자체 스타터킷 제작(재작성) → Gumroad/크몽 판매 개시
3개월차  반응 좋으면 강의·컨설팅 확장 / 아니면 B-2 프로토타입으로 전환
```

| 시장 | 메모앱은 옵시디언/노션이 장악한 레드오션 |

> **결론: "앱"이 아니라 "AI 개발 노하우"를 판다. 이 레포는 팔 상품이 아니라
> 실력을 증명하는 포트폴리오이자 교보재로 쓸 때 가치가 가장 크다.**

## 10. 확장 가능성 (React / PHP)

### React

이미 React다. `apps/desktop/src/`가 100% React 19 + TypeScript이며, Rust는
파일 I/O·검색·워처 등 네이티브 경계에만 쓰인다. **React를 아는 사람이 이 프로젝트의
대부분을 다룰 수 있다.**

### PHP

데스크탑 앱에는 부적합하다. PHP는 서버 사이드 언어이고, 네이티브 창·파일시스템 감시·
트레이 같은 것을 다루지 못한다.

### 대안 조합

| 조합 | 난이도 | 특징 |
|---|---|---|
| React + Tauri (현재) | 중 | 가장 가볍고 빠름. Rust 일부 필요 |
| React + Electron | 하 | Rust 불필요, JS만으로 가능. 대신 무거움 |
| React + PHP 백엔드 | — | 데스크탑 앱은 불가. **웹 버전**을 만들 때는 유효한 조합이나, 로컬 우선이라는 핵심 장점을 잃음 |
